# Документация по автотестам проекта Goagro

## 🛠 Технический стек и Архитектура
* **Инструментарий:** Playwright + TypeScript
* **Паттерн проектирования:** Page Object Model (POM) + Component Object Model.
* **Управление состоянием:** Глобальная авторизация через `auth.setup.ts`. Состояние браузера (токены/куки) сохраняется в `playwright/.auth/user.json` и автоматически применяется ко всем тестам внутренних страниц для мгновенного доступа без повторного логина.
* **Безопасность:** Чувствительные данные (логины, пароли) вынесены в файл `.env`.

---

## 📁 Структура проекта
* `playwright.config.ts` — главный конфигурационный файл, точка входа.
* `tests/auth.setup.ts` — скрипт генерации сессии (Global Setup).
* `pages/base.page.ts` — базовый класс с общими методами, от которого наследуются остальные страницы.
* `pages/login.page.ts` — инкапсулированная логика страницы авторизации.
* `tests/auth.spec.ts` — изолированный набор тестов проверок формы логина.
