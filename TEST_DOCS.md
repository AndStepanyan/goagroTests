# Документация по автотестам проекта Goagro

## 🛠 Технический стек и Архитектура
* **Инструментарий:** Playwright + TypeScript
* **Паттерн проектирования:** Page Object Model (POM) + Component Object Model.
* **Управление состоянием:** Глобальная авторизация через `auth.setup.ts`. Состояние браузера (токены/куки) сохраняется в `playwright/.auth/user.json` и автоматически применяется ко всем тестам внутренних страниц для мгновенного доступа без повторного логина.
* **Безопасность:** Чувствительные данные (логины, пароли) вынесены в файл `.env`.

---

## 📁 Структура проекта
* `playwright.config.ts` — конфигурация отдельных `api` и `chromium` проектов.
* `api/` — клиенты для переиспользуемых API-операций.
* `pages/` — Page Object'ы пользовательского интерфейса.
* `tests/api/` — API-сценарии.
* `tests/ui/` — браузерные сценарии, сгруппированные по функциональности.
* `tests/fixtures/` — расширения стандартных Playwright fixtures.
* `tests/helpers/` — небольшие общие утилиты тестов.
* `tests/auth.setup.ts` — подготовка и сохранение браузерной сессии.

## ▶️ Команды
* `npm test` — запустить все тестовые проекты.
* `npm run test:web` — запустить только UI-тесты в Chromium.
* `npm run test:api` — запустить только API-тесты.
* `npm run test:headed` — запустить тесты с видимым браузером.
* `npm run test:ui` — открыть интерактивный интерфейс Playwright.
* `npm run typecheck` — проверить TypeScript без запуска тестов.

URL приложения, URL API и тестовые учётные данные задаются через `.env`.
Список поддерживаемых переменных находится в `.env.example`.
